# Автоматизированное тестирование в средах разработки

Практический проект к курсовой работе **«Анализ встроенных систем автоматизированного тестирования в средах разработки»**.

## Что проверяется

Учебный модуль обработки заявок: обязательный код, количество от 1 до 1000,
положительная цена, скидка от 0 до 50 %, расчёт итоговой суммы, переход статуса
«новая» → «в работе» → «выполнена».

В трёх средах демонстрируются аналогичные **T01–T05**: обычная заявка, пустое
поле, отрицательное количество, минимальное количество и изменение статуса.
Дополнительно есть проверки цены, скидки, округления и других границ.

| Среда | Язык | Фреймворк | Где находится проект |
| --- | --- | --- | --- |
| Visual Studio Code | Python 3.10+ | pytest | `src/` и `tests/` |
| IntelliJ IDEA | Java 17 | JUnit 5 / Maven | `intellij-idea/` |
| Visual Studio | C# / .NET 8 | MSTest | `visual-studio/TestingDemo.Tests/` |

## 1. Запуск в Visual Studio Code (Python / pytest)

Откройте корневую папку проекта в VS Code и в терминале выполните:

**Windows PowerShell:**

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -v
```

**Linux/macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -v
```

Чтобы тесты появились в панели Testing: установите расширение **Python** от
Microsoft, выберите интерпретатор `.venv`, откройте панель **Testing** и включите
**pytest** в разделе настройки тестирования. При необходимости запустите
**Python: Configure Tests** через палитру команд.

Проверенный результат для этого проекта в текущем окружении:

```text
....................  [100%]
20 passed
```

Длительность запуска зависит от компьютера и не является характеристикой IDE.

## 2. Запуск в IntelliJ IDEA (Java / JUnit 5)

Откройте папку `intellij-idea` как Maven-проект. Убедитесь, что установлен JDK 17,
дождитесь загрузки зависимостей, откройте `RequestProcessorTest.java` и нажмите
зелёный треугольник рядом с классом. Результат появится в **Run**.

Командный вариант (если установлен Maven):

```bash
cd intellij-idea
mvn test
```

## 3. Запуск в Visual Studio (C# / MSTest)

Откройте файл `visual-studio/TestingDemo.Tests/TestingDemo.Tests.csproj` в
Visual Studio 2022 с установленным **.NET 8 SDK** и нагрузкой .NET desktop
development. Затем выберите **Test → Test Explorer → Run All Tests**.

Командный вариант (если установлен .NET SDK):

```bash
dotnet test visual-studio/TestingDemo.Tests/TestingDemo.Tests.csproj
```

**Важно:** Python/pytest реально запущен и проверен. Проекты C#/MSTest и
Java/JUnit подготовлены в качестве эквивалентных примеров, но локальный запуск
их тестов здесь не проводился, поскольку .NET SDK и Maven отсутствуют. Не нужно
выдавать их за проверенные без запуска на вашем компьютере.

## Что показывает пример и чего он не показывает

- Автоматическое обнаружение, запуск и анализ тестов в IDE.
- Граничные и негативные проверки, сообщения о неуспехе.
- Возможность запустить Python-тесты и без графического интерфейса.
- GitHub Actions автоматически запускает **только Python-тесты** при коммитах.

В курсовой также приведён **условный расчёт** 18/20 = 90 %. Это пример метода
подсчёта, а не фактический результат кода из репозитория. Фактический проверенный
результат Python-версии на момент подготовки проекта — **20/20**.

Для объективного сравнения производительности разных IDE потребуются запуск на
одном компьютере, одинаковые тестовые сценарии и фиксация версий ПО.

## Публикация на GitHub и QR-код

1. Создайте новый репозиторий на GitHub, например `ide-automated-testing-coursework`.
2. Загрузите в него **содержимое этой папки** (включая скрытую `.github`).
3. Убедитесь, что ссылка на репозиторий открывается.
4. QR-код в курсовой должен вести на реальную ссылку вида
   `https://github.com/USERNAME/ide-automated-testing-coursework`, где `USERNAME`
   заменяется вашим логином. Это **шаблон**, не готовый адрес.

Никогда не публикуйте токены, пароли и личные данные внутри репозитория.
